# 《水浒传》漏洞审计 · 内置模型直审样本

> 方法：CodeBuddy 内置模型（Hy3）直接 `read_file` 读取原文做语义审计，**不调用任何外部 API / LLM 端点**。
> 本次样本范围：第 1 回（洪太尉误走妖魔）、第 23 回（武松打虎）、第 24 回（潘金莲）。
> 对照：之前 `shuihu_llm_audit.py` 走 `OpenAIProvider` → 外部 DeepSeek 端点，且为**逐章孤立**调用。

## 一、总体结论

样本三回文本**内部自洽度高**，未检出硬情节漏洞。主要问题集中在世界构建层（时代错位）与微小道具连续性，均非致命矛盾。

## 二、发现清单

### [软·跨全书] 时代错位（世界构建层）
- 第 1 回设定在 **仁宗嘉祐三年（1058）**，洪太尉放走 108 魔君，"天罡星合當出世"。
- 主体故事发生在 **徽宗政和/宣和（约 1119）**，相隔约 **60 年**。
- 写实逻辑下，魔君"出世"与宋江起义跨度过大；但被"天罡星合當出世"的神话框架化解。
- 判定：**软不一致**，非硬漏洞，属古典小说常见的神话压缩。

### [轻微] 道具连续性遗漏
- 第 23 回武松哨棒打折为"棒橛"（line 18），下冈时"來松樹邊尋那打折的棒橛……把棒橛又打了一回"（line 26），明确"拿了棒橛"下冈。
- 但至上户家（line 28）、见阳谷知县（line 29）后，此道具再无交代，抬虎用"虎床"、武松坐"兜轿"。
- 判定：微小道具消失，不影响情节，属叙述省略。

### [轻微·口头文学特征] 数字夸张差异
- 第 23 回酒家称虎"壞了**三二十條**大漢性命"（line 11）；
- 同回猎户称过往客人"**不記其數**，都被這畜生喫了"（line 27）。
- 判定：二者为概括性夸张，非逻辑矛盾，是说话人视角差异。

## 三、重要验证：澄清一个"传说级漏洞"

**常见说法**：武松离兄时长前后矛盾（武松说"一年余"，武大/旁白说"三五年"）。

**实测原文（第 23、24 回）**：
- 第 23 回武松："今已**一年有餘**"（line 4）；
- 第 24 回武松对武大："**一年有餘**不見哥哥"（line 2）；
- 武大回应仅"你去了**許多時**"，无具体数字。

→ **该矛盾在样本内不成立**。逐章孤立调用的 LLM 易把此类"文学常识"当确证漏洞报出；内置模型因直接读原文、跨回对照，可即时证伪。
